# GameZone React Frontend

Modern gaming website built with React + Vite.

## Includes
- Gaming home page
- Featured games and filters
- India Gaming Centers directory
- City filters for Surat, Ahmedabad and Mumbai
- Directions buttons
- Frontend booking/enquiry form
- Leaderboard
- Gaming news
- Community section
- Login/Register modal
- Responsive mobile design

## Run
```bash
npm install
npm run dev
```

No backend is required. Forms are frontend/demo interactions only.
